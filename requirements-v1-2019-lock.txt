# AirSense V1 - runtime lock file
# ======================================================================
# Purpose
# ----------------------------------------------------------------------
# requirements-v1-2019.txt declares the seven DIRECT historical
# dependencies. Installing those seven today causes pip to resolve their
# TRANSITIVE dependencies to whatever is newest and still importable on
# CPython 3.6 - which in practice means 2020-2026 releases. An unlocked
# install produced 57 post-cutoff distributions out of 69, so the direct
# pins alone do NOT produce a historical runtime.
#
# This file pins the complete transitive closure to releases published on
# or before the cutoff, so the environment is reproducibly historical.
#
# Hard historical cutoff : 2019-04-26
# Reference interpreter  : CPython 3.6.7
#
# requirements-v1-2019.txt is the authoritative DIRECT dependency list and
# is NOT modified by this file. Every direct pin below repeats it exactly.
#
# Every version here was verified against the PyPI JSON API as published
# on or before 2019-04-26. Release dates are recorded in the comments.
#
# Selection rule: the newest release published on or before the cutoff
# that is compatible with CPython 3.6 AND satisfies the version
# constraints declared by the other pinned packages. Where the newest
# pre-cutoff release by date would break a declared constraint, the
# constraint wins and the reason is noted inline.
# ======================================================================
